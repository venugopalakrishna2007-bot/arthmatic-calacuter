ARITHMETIC CALCULATOR

How to run in Visual Studio Code:
1. Extract Arithmetic_Calculator.zip.
2. Open Visual Studio Code.
3. Select File > Open Folder.
4. Choose the Arithmetic_Calculator folder.
5. Open index.html.
6. Right-click inside index.html and choose "Open with Live Server" (if Live Server extension is installed).
   Or double-click index.html to open it directly in your browser.

Files:
- index.html : webpage structure
- style.css  : design and layout
- script.js  : calculator operations

Features:
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Decimal values
- Clear (AC) and delete (DEL)
- Keyboard support
